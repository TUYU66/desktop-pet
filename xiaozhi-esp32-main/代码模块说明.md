# xiaozhi-esp32-main 代码模块说明

本文按功能介绍源码模块，实际编译清单以 `main/CMakeLists.txt` 为准。当前固件固定为 ESP32-S3、`bread-compact-wifi-lcd` 板型，使用 LCD、数字 I2S 麦克风/功放、ESP-SR AFE 和 WebSocket 通信。

## 程序入口与业务流程

`main.cc`：（ESP-IDF 程序入口；初始化 NVS，创建并启动全局应用。）

`application.cc`：（程序总控制器；初始化、主事件循环、联网可用性与应用生命周期。）

`application_protocol.cc`：（服务器协议回调；解析下发消息并投递到主循环。）

`application_conversation.cc`：（聆听、唤醒、对话状态切换和音频状态更新。）

`application_updates.cc`：（资源检查、版本检查及激活提示。）

`device_state_machine.cc`：（设备状态机；管理启动、空闲、监听、说话和升级等状态及其合法切换。）

`settings.cc`：（配置存储；封装 NVS 中字符串、整数和布尔值的读取、保存与删除。）

`system_info.cc`：（系统信息；收集芯片、MAC、内存、固件版本和设备标识，用于上报与诊断。）

`ota.cc`：（联网配置与升级；访问 OTA 接口取得服务器配置，检查新固件并执行升级。）

`assets.cc`：（资源管理；读取资源分区中的字体、表情和提示音，并处理资源包更新。）

`mcp_server.cc`：（设备工具服务；向 AI 提供音量、屏幕亮度、LED 等设备能力并执行调用。）

## 当前开发板与硬件

`boards/bread-compact-wifi-lcd/compact_wifi_board_lcd.cc`：（当前开发板实现；初始化 ST7789 屏幕、按键、背光、单灯以及 I2S 麦克风和扬声器。）

`boards/bread-compact-wifi-lcd/stm32_link.cc`：（底盘连接初始化、蓝牙提示、状态快照和请求生命周期。）

同目录 `stm32_link_protocol.cc` 负责帧编码、字段校验和调参持久化辅助；`stm32_link_receive.cc` 负责串口接收及回执解析；`stm32_link_motion.cc` 负责动作请求；`stm32_link_tuning.cc` 负责电机校准和在线调参请求。`stm32_link_internal.h` 仅为这些实现文件共享协议细节，不对应用提供第二套接口。

`boards/common/board.cc`：（开发板基类；提供显示、音频、网络、设备信息和状态读取等通用接口。）

`boards/common/wifi_board.cc`：（Wi-Fi 开发板基类；管理联网、热点配网、网络事件和网络状态图标。）

`boards/common/button.cc`：（按键驱动；处理消抖、按下、释放、单击、双击和长按事件。）

`boards/common/backlight.cc`：（背光驱动；通过 PWM 调整屏幕亮度，并保存用户设置。）

## 音频链路

`audio/audio_codec.cc`：（音频设备抽象；定义采样率、音量、输入输出启停和音频读写接口。）

`audio/codecs/no_audio_codec.cc`：（当前音频硬件驱动；直接控制 ESP32-S3 I2S 数字麦克风和 I2S 功放。）

`audio/audio_service.cc`：（音频流水线；负责录音、播放、Opus 编解码、重采样、VAD、回声消除和唤醒词任务。）

`audio/processors/afe_audio_processor.cc`：（AFE 语音前处理；使用 ESP-SR 完成降噪、VAD，以及启用时的设备端回声消除。）

`audio/wake_words/afe_wake_word.cc`：（AFE 唤醒词检测；持续分析麦克风数据，识别唤醒词后通知应用层。）

`audio/demuxer/ogg_demuxer.cc`：（OGG 解析；从 OGG 容器中提取 Opus 数据包供播放链路解码。）

## 屏幕与指示灯

`led/single_led.cc`：（单颗 LED 驱动；根据设备状态控制常亮、熄灭和闪烁效果。）

`display/display.cc`：（显示抽象基础；维护状态文本、聊天内容、表情和通知等公共显示数据。）

`display/lcd_display.cc`：（LCD 显示基础；连接 ESP LCD 面板与 LVGL，并处理屏幕开关和刷新。）

`display/lcd_appearance.cc`：（LCD 主题、表情、颜色、状态表情联动和字幕显隐；与 UI 创建共用原来的显示锁。）

`display/lvgl_display/lvgl_display.cc`：（LVGL 页面实现；绘制顶部状态栏、聊天区域、表情和通知界面。）

`display/lvgl_display/emoji_collection.cc`：（表情集合；查找和管理资源包中的表情图像。）

`display/lvgl_display/lvgl_theme.cc`：（界面主题；统一设置颜色、背景、气泡和控件样式。）

`display/lvgl_display/lvgl_font.cc`：（字体适配；把资源分区中的字体转换为 LVGL 可使用的字体对象。）

`display/lvgl_display/lvgl_image.cc`：（图像适配；把资源图像封装为 LVGL 可显示对象并管理其内存。）

`display/lvgl_display/gif/lvgl_gif.cc`：（GIF 控件；把 GIF 解码器接入 LVGL，控制动画创建、刷新和释放。）

`display/lvgl_display/gif/gifdec.c`：（GIF 解码；解析 GIF 帧、调色板、透明色和帧延迟。）

## 网络协议

`protocols/protocol.cc`：（协议公共层；统一会话状态、音频包发送和服务器消息回调接口。）

`protocols/websocket_protocol.cc`：（当前网络协议；建立 WebSocket 连接，交换 JSON 控制消息和二进制音频数据。）

## 依赖说明

`78/esp-ml307` 这个组件名虽然带有 `ml307`，但当前项目仍需要它提供通用的 `NetworkInterface`、`Http` 和 `WebSocket` 抽象。固件没有实例化或使用其中的蜂窝网络板级驱动，因此它不是误留的硬件功能代码。
