# React Bits component

`ClickSpark.tsx` is vendored from David Haz's React Bits:
https://github.com/DavidHDev/react-bits/blob/main/src/ts-default/Animations/ClickSpark/ClickSpark.tsx

Retrieved 2026-10-18. Copyright (c) 2026 David Haz. The original MIT + Commons Clause
license is preserved in `LICENSE.md`. This component is used as part of the desktop-pet
application, not distributed as a standalone component product.

The application's `CompanionCard` supplies small, muted sparks and disables them on
touch-sized viewports and whenever reduced motion is requested. No additional React
Bits runtime, Three.js, Tailwind, Lenis or Vanta dependency is required.
