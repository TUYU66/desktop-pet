# 统一表情与 MCP

待机轮换、聊天情绪、MCP 都使用 RoboEyes 的同一份表情定义（眼形、嘴形、视线和特效）。

| 表情 | 特效 |
| --- | --- |
| neutral 普通 | 无 |
| happy / laughing / winking 开心、大笑、眨眼 | 星星 |
| loving 喜爱 | 爱心 |
| curious / confused 好奇、疑惑 | 问号 |
| surprised / confident 惊讶、自信 | 光芒 |
| shy 害羞 | 腮红 |
| sad / crying 难过、哭泣 | 泪滴 |
| angry 生气 | 生气符号 |
| tired / yawn 疲惫、打哈欠 | 呼气 |
| sleepy 困倦 | Zzz |
| peek_left / peek_right 左右偷看 | 方向符号 |
| daydream 发呆 | 浮动省略号 |

共有 19 个基础表情定义，兼容 embarrassed、funny 等旧名称。待机只从其中 11 个轻松表情中轮换，不选哭泣、生气等；待机两分钟后加入困倦和打哈欠。

MCP 指定表情保持约 8 秒，期间普通聊天情绪和状态切换不覆盖它；音乐和提醒可以打断。表情结束后恢复普通状态。说话嘴形叠加在共享表情上，普通回复无特效。音乐音符与提醒庆祝仍由功能状态管理。

服务端根据回复前部的 emoji 下发表情，不另行调用情绪模型。无标记默认为 neutral。聊天基础提示已补充按语境选表情规则；长期记忆提示未改动。

## 手动验证

编译烧录 ESP32 并重启 Python 服务。分别尝试普通说明、开心回复、难过回复，以及“哭一个”“向左偷看”“眨个眼”。确认普通说话无粒子，情绪特效与嘴形共存；验证 MCP 表情保持、到期恢复和音乐/提醒切换。静置检查待机轮换；确认眼睛嘴巴独立改色保持有效。

本次仅做静态检查，未执行固件编译或硬件测试。

## 颜色保存

眼睛、嘴巴颜色分别保存在设备 NVS 的 face 命名空间中，改色后自动保存，重启恢复。省略某个颜色不会修改该项；重复设置相同颜色不重复写入 Flash。恢复默认颜色也会保存。首次升级后需重新设置一次想要的颜色；清除 NVS 或整片擦除会重置颜色。
