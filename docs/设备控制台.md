# 设备控制台

概览页提供设备状态、音量、屏幕亮度、表情预览，以及眼睛与嘴巴颜色。最近对话预览最新三条消息。

## 更新范围

需要更新 ESP32 固件、Python 服务、Java 服务和网页前端。本次只做静态检查，编译与设备验证由用户进行。

旧固件仍可尝试读取原有硬件状态；未上报的活动状态和颜色显示为“未上报”，不能核对实际颜色的表情控件会禁用。完整功能需要支持 `self.dashboard.get_state` 的固件。

## 控制与状态

- 设备状态每 6 秒读取一次；提醒每 15 秒刷新。网页隐藏时暂停定时读取。
- 多台设备在线时手动选择设备；只有一台时自动选择。
- 音量和亮度使用滑条调节，松开时提交一次。控制过程显示“正在发送，等待设备确认”。收到设备执行回执并重新读取到目标值后，才显示成功。
- 请求超时表示执行结果未知，请刷新核实；不会自动重发控制命令。
- 眼睛和嘴巴颜色独立设置，保存到设备，重启保留。
- 表情预览约 8 秒；音乐播放或准备播放时禁用预览，保留音乐表情。
- 音乐播放或准备播放状态来自 Python 播放器，用于保护表情预览。

## 服务连接

前端经 Java 的 `/xiaozhi/api/devices/panel` 访问 Python 的 `/xiaozhi/device/panel`，设备指令经 MCP 下发。

Java 和 Python 在同一台电脑并使用本机回环地址连接时，无须新增配置。跨机器或容器网络连接时，需要在两个服务的环境变量中设置相同的 `XIAOZHI_DEVICE_SERVICE_KEY`，再重启服务。密钥只配置在服务端。

## 手动验收

1. 连接设备，确认概览页能显示状态、实际音量与亮度。
2. 分别拖动音量、亮度滑条并松开，确认设备发生变化，网页收到核对成功反馈。
3. 预览表情，分别修改眼睛、嘴巴颜色，重启设备确认颜色保留。
4. 播放音乐，确认状态显示“播放音乐”、表情预览禁用。
5. 确认最近对话只显示最新三条消息。
6. 断开设备，确认页面不再宣称执行成功；重新连接并刷新后恢复控制。
