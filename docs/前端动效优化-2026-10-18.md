# 前端动效优化

## 存档

开始修改前的本地 Git 提交：`31c3324`（包含此前的 Notion 界面和每轮 45 秒提醒规则）。
本次没有推送 GitHub，没有修改固件或后端业务规则。

## 实现

- GSAP + 官方 `@gsap/react`：按页面作用域组织内容入场、后续消息追加和原生详情展开。异步加载的内容通过观察器发现，每个分组只播放一次；轮询文本变化不重播。离开页面时清理观察器、事件和动画。
- React Bits ClickSpark：仅用于概览名片，保留来源和许可证，火花结束即清理画布。
- 概览：保留现有名片构图，小兰的脸和五官轻微跟随鼠标，移出后复位。
- 聊天：历史加载不逐条入场，后续追加消息提供轻量反馈；输入框聚焦及发送按钮有交互提示。
- 记忆：分组进入、分类标记、纸面扫光和详情展开反馈。
- 提醒：待处理区域书签标记、需回应时间点提示和详情展开；不改变提醒时长或确认、延后操作。
- 音乐：切歌时封面入场，真实播放时出现浮动音符，暂停后隐藏，活动歌词增加侧边标记。
- 设置：表单聚焦提示，名称、称呼、音色和唤醒词预览变化有短暂高亮；高亮不代表保存成功。

## 范围与验证

新增 GSAP 动效限桌面宽度（大于 760px），尊重系统的减少动态效果偏好。
没有接入 Lenis 或 Vanta，没有接管聊天、歌词或弹窗的滚动。
`npm run build`、`npm run lint` 和 Git 空白检查通过；lint 仍有原有警告。
浏览器使用拦截 API 的演示数据验证六个主要页面、1440px/830px 桌面布局、设置预览、名片互动及动态偏好切换；未向硬件发送控制指令。
